# Brand / source logo

Drop the app logo here so it can be wired into the home-screen icon.

**Upload it as:** `brand/logo.png`

**Ideal format:**
- Square PNG (e.g. 1024×1024 or 512×512 — bigger is fine, it gets scaled down)
- Transparent or solid background, whatever you want the icon to look like

Once `brand/logo.png` is committed, it gets turned into:
- `public/icons/` app icons
- the PWA manifest icons (Android home screen)
- the Apple touch icon (iOS "Add to Home Screen")
- the browser favicon
